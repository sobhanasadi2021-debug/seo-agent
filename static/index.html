    🔎 حالت دستی — تحلیل و مشاوره

    1. به تب «تحلیل و مشاوره» برو و فقط آدرس سایت را وارد کن.
    2. سایت‌های لوکال هم کار می‌کنند؛ مثلاً localhost:3000 یا 127.0.0.1:8000 — ایجنت خودش http را تشخیص می‌دهد.
    3. دکمه «شروع تحلیل» را بزن؛ ایجنت صفحه اصلی و صفحات داخلی را می‌خزد.
    4. گزارش کامل می‌آید: امتیاز ۰-۱۰۰، گرید، بررسی‌های فنی، کلمات کلیدی، وضعیت GEO و ربات‌های AI.
    5. از بخش «توصیه‌های بهبود» اولویت‌دار شروع کن؛ هر مورد راهکار عملی فارسی دارد.
    6. گزارش را HTML یا CSV (اکسل) دانلود کن و برای تیم بفرست — یا متن گزارش را کپی کن.

    ⚡ حالت خودکار — اتصال به وردپرس

    1. آدرس سایت + آدرس پنل ادمین + نام کاربری و رمز مدیر را وارد کن.
    2. اول «تست اتصال» را بزن تا از درستی اطلاعات مطمئن شوی.
    3. اقدامات دلخواه را تیک بزن (متا دیسکریپشن، کلمه کلیدی، تگ، توضیح سایت).
    4. «شروع سئوی خودکار» را بزن و لاگ زنده را ببین؛ هر لحظه می‌توانی لغو کنی.
    5. خلاصه تغییرات را ببین و گزارش HTML را دانلود کن.
    💡 پیشنهاد امن: به‌جای رمز اصلی، از Application Password استفاده کن: وردپرس ← کاربران ← پروفایل ← Application Passwords. اگر افزونه غیرفعال‌کننده XML-RPC داری، ایجنت به‌طور خودکار از REST API استفاده می‌کند.

    🤖 GEO چیست؟

    GEO (Generative Engine Optimization) یعنی بهینه‌سازی برای موتورهای پاسخ هوش مصنوعی مثل ChatGPT، Perplexity و Gemini. ایجنت این موارد را بررسی و اصلاح می‌کند:

    • مسدود نبودن ربات‌های AI در robots.txt (GPTBot، ClaudeBot، PerplexityBot و…)
    • وجود فایل llms.txt برای معرفی سایت به مدل‌های زبانی
    • داده ساختاریافته (Schema) به‌ویژه FAQPage و Article و Breadcrumb
    • پاراگراف‌های کوتاه قابل نقل‌قول + تاریخ انتشار + نام نویسنده (سیگنال E-E-A-T)

    🔒 امنیت و محدودیت‌ها

    • رمز عبور فقط در حافظه سرور محلی نگه‌داری می‌شود و هرگز روی دیسک ذخیره نمی‌شود.
    • به‌صورت پیش‌فرض سرور فقط روی 127.0.0.1 (کامپیوتر خودت) اجرا می‌شود؛ از اینترنت قابل دسترسی نیست.
    • در حالت خودکار، فیلدهایی که قبلاً پر شده‌اند بازنویسی نمی‌شوند.
    • تغییر فایل‌های قالب و robots.txt به‌صورت مستقیم انجام نمی‌شود؛ توصیه دقیق آن در گزارش می‌آید.
    • برخی هاست‌ها XML-RPC را می‌بندند — ایجنت خودکار به REST API سوئیچ می‌کند.
    • اگر روی هاست عمومی دیپلوی کردی، متغیر محیطی AGENT_TOKEN را ست کن تا APIها قفل شوند؛ سپس پنل را با ?token=... باز کن.
    • تحلیل «localhost» یعنی لوکالِ همان سیستمی که ایجنت روی آن اجراست؛ روی هاست ابری، لوکالِ همان سرور است.

    🌍 استقرار رایگان (دیپلوی)

    • Render — راحت‌ترین: New Web Service از گیت؛ Start Command را python app.py بگذار؛ پورت خودکار از متغیر PORT خوانده می‌شود. پلن رایگان بعد از ۱۵ دقیقه بی‌فعالیتی می‌خوابد.
    • Hugging Face Spaces — رایگان؛ SDK را Docker انتخاب کن و همین پوشه را push کن (Dockerfile آماده است، پورت 7860).
    • Koyeb — یک سرویس رایگان Docker/Python.
    • Oracle Cloud Always Free — یک VM واقعی همیشه‌روشن (نیازمند ثبت‌نام با کارت).
    • ⚠️ PythonAnywhere پلن رایگان مناسب نیست: خروج اینترنت به دامنه‌های دلخواه محدود است و خزش سایت‌ها کار نمی‌کند.
    • ⚠️ Vercel / Netlify / Cloudflare Workers مناسب نیستند (serverless و بدون پروسه ماندگار).
