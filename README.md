# سئو ایجنت — ایجنت کامل SEO + GEO

ابزار تحت وب برای **تحلیل و بهینه‌سازی سئو** و **GEO (بهینه‌سازی برای موتورهای هوش مصنوعی)** — با دو حالت **دستی** و **خودکار**، رابط فارسی راست‌به‌چپ، تم تیره/روشن و **بدون هیچ وابستگی خارجی** (فقط پایتون استاندارد).

## 🚀 اجرا

```bash
# ویندوز: دابل‌کلیک روی
run.bat

# لینوکس/مک
bash run.sh

# یا مستقیم:
python app.py
```

سپس مرورگر روی `http://127.0.0.1:8791` باز می‌شود. *(نیازی به `pip install` نیست.)*

## ✨ امکانات

### حالت دستی — تحلیل و مشاوره (فقط با آدرس سایت)
- خزش صفحه اصلی + تا ۱۲ صفحه داخلی با نمایش زنده پیشرفت
- **امتیاز ۰ تا ۱۰۰ + گرید (A+ تا F)** با امتیاز تفکیکی: متا، محتوا، فنی، GEO، ساختار
- بررسی کامل متا تگ‌ها (Title، Description، Canonical، OG، Twitter، Viewport، lang، favicon…)
- ساختار هدینگ‌ها، متن جایگزین تصاویر، لینک‌های داخلی/خارجی و **تشخیص لینک خراب**
- **استخراج کلمات کلیدی** فارسی/انگلیسی (تک‌کلمه‌ای، دوکلمه‌ای، سه‌کلمه‌ای) با وزن‌دهی به عنوان و تیترها + پیشنهاد عنوان و متا دیسکریپشن جدید
- پیش‌نمایش نتیجه در گوگل (SERP Preview)
- بررسی فنی: HTTPS، robots.txt، sitemap، فشرده‌سازی، زمان پاسخ سرور، Mixed Content، HSTS…
- **بخش GEO**: وضعیت ۱۲ ربات هوش مصنوعی (GPTBot، ClaudeBot، PerplexityBot، Google-Extended و…)، فایل llms.txt، داده ساختاریافته، FAQ، پاراگراف‌های قابل نقل‌قول و سیگنال‌های E-E-A-T
- **توصیه‌های اولویت‌دار** با راهکار عملی فارسی
- خروجی: **گزارش HTML** آماده چاپ/اشتراک، **JSON**، کپی متن گزارش
- **تاریخچه** تحلیل‌ها با مشاهده/دانلود/حذف

### حالت خودکار — اتصال به وردپرس (لینک + یوزر/پس ادمین)
- **دکمه تست اتصال** قبل از اجرا (تشخیص وردپرس، XML-RPC/REST، افزونه سئو فعال، دسترسی پنل ادمین)
- ورود خودکار و اعمال بهبودها روی مطالب:
  - **متا دیسکریپشن** خودکار برای هر مطلب (Yoast، Rank Math و AIOSEO — فیلدهای پرشده بازنویسی نمی‌شوند)
  - **کلمه کلیدی فوکوس** برای هر مطلب
  - **تگ‌های پیشنهادی** (اختیاری)
  - **توضیح کوتاه سایت** (اگر خالی باشد)
- گزینه **«فقط تحلیل بدون تغییر»** برای بررسی امن
- **لاگ زنده** مرحله‌به‌مرحله + **دکمه لغو** در هر لحظه + خلاصه تغییرات + دانلود گزارش و لاگ
- اگر XML-RPC بسته باشد، خودکار به **REST API** سوئیچ می‌شود

## 🔒 امنیت
- رمز عبور وردپرس فقط در حافظه نگه‌داری می‌شود و هرگز روی دیسک ذخیره نمی‌شود.
- لوکال: سرور روی `127.0.0.1` اجرا می‌شود (از اینترنت قابل دسترسی نیست).
- **روی هاست عمومی:** متغیر محیطی `AGENT_TOKEN` را ست کنید.
  - توکن **هرگز در URL نمی‌آید** — در مرورگر در `localStorage` ذخیره و در هدر `X-Agent-Token` ارسال می‌شود.
  - اگر لینکی با `?token=...` باز شود، توکن یک‌بار ذخیره و **بلافاصله از نوار آدرس پاک می‌شود**.
  - دکمه 🔑 در نوار بالا برای وارد کردن/تغییر توکن است.
  - لاگ‌های سرور query string را لاگ نمی‌کنند (نبود نشت توکن در لاگ‌ها).
- پیشنهاد: استفاده از **Application Password** وردپرس به‌جای رمز اصلی (کاربران ← پروفایل ← Application Passwords).
- ℹ️ تاریخچه تحلیل‌ها روی دیسک کانتینر ذخیره می‌شود؛ در پلن‌های رایگان ابری (مثل Railway) با هر دیپلوی جدید خالی می‌شود.

## 🌍 استقرار رایگان (دیپلوی)

چون ایجنت هیچ وابستگی‌ای ندارد، روی هر جایی که پایتون ۳.۸+ اجرا شود بالا می‌آید. سرور به‌صورت خودکار `PORT` و `HOST` را از متغیر محیطی می‌خواند:

| هاست | نحوه دیپلوی | نکته |
|---|---|---|
| **Koyeb** (پیشنهاد اول — ۲۴/۷) | Create App ← GitHub ← همین مخزن ← Builder: **Dockerfile** ← Env: `AGENT_TOKEN` | یک سرویس رایگان همیشه‌روشن (512MB، بدون کارت بانکی، بدون خواب) — راهنمای قدم‌به‌قدم پایین |
| **Render** | New Web Service ← مخزن گیت ← Start: `python app.py` | پورت خودکار؛ ⚠️ پلن رایگان بعد از ۱۵ دقیقه بی‌فعالیتی می‌خوابد |
| **Oracle Cloud Always Free** | نصب پایتون روی VM و اجرای سرویس | VM واقعی همیشه‌روشن (ثبت‌نام با کارت) |

### 🚀 دیپلوی روی Koyeb (رایگان، همیشه‌روشن)

۱. این پوشه را به یک مخزن گیت‌هاب push کنید:
```bash
git init && git add -A && git commit -m "seo-agent"
git remote add origin https://github.com/USERNAME/seo-agent.git
git push -u origin main
```
۲. در [app.koyeb.com](https://app.koyeb.com) → **Create App** ← منبع **GitHub** ← مخزن `seo-agent`
۳. Builder: **Dockerfile** (پورت از خودِ Dockerfile: 7860) — Start command خالی بماند
۴. در بخش **Environment variables** مقدار `AGENT_TOKEN` را از `.env.example` وارد کنید
۵. Instance: **Free** ← **Deploy** — آدرس عمومی به شکل `https://xxx-yyy.koyeb.app/` داده می‌شود

> هر آپدیت بعدی: فقط `git push` کنید تا خودکار دوباره دیپلوی شود.

- ⚠️ **PythonAnywhere** پلن رایگان مناسب نیست: خروج اینترنت به دامنه‌های دلخواه مسدود است و خزش سایت‌ها کار نمی‌کند.
- ⚠️ **Vercel / Netlify / Cloudflare Workers** مناسب نیستند: serverless هستند و پروسه ماندگار (تسک پس‌زمینه و polling) ندارند.
- 🔒 **روی هاست عمومی حتماً** متغیر محیطی `AGENT_TOKEN` را ست کنید (یک رشته تصادفی). پنل را باز کنید و با دکمه 🔑 توکن را یک‌بار وارد کنید؛ در غیر این صورت هر کسی می‌تواند از سرور شما سایت‌ها (و حتی شبکه داخلی سرور) را تحلیل کند.
- ℹ️ تحلیل «localhost» یعنی لوکالِ سیستمی که ایجنت روی آن اجراست — روی سیستم خودتان سایت‌های محلیتان، روی سرور ابری لوکالِ همان سرور.
